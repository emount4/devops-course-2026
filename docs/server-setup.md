# Конфигурация виртуальной машины devops-vm

## 1. Параметры машины

- Имя виртуальной машины: `devops-vm`
- Оперативная память: 2048 МБ
- Процессор: 2 ядра
- Диск: 25 ГБ, динамически расширяемый
- Гостевая ОС: Ubuntu Server

## 2. Сетевые интерфейсы

### Адаптер 1 — NAT

- Интерфейс: `enp0s3`
- IPv4-адрес: `10.0.2.15`
- Назначение: доступ виртуальной машины в Интернет

### Адаптер 2 — Host-only

- IPv4-адрес: `192.168.56.102`
- Назначение: прямой доступ к виртуальной машине с хостовой системы

На хостовой системе в файл `hosts` добавлена запись:

192.168.56.102 devops.local

## 3. Правило проброса портов

VirtualBox, адаптер NAT:

- Имя правила: `ssh`
- Протокол: TCP
- Адрес хоста: `127.0.0.1`
- Порт хоста: `2222`
- Адрес гостя: не задан
- Порт гостя: `2222`

## 4. Учётные записи

### domashev

- UID: 1000
- Исходная учётная запись, созданная при установке системы
- Использовалась для первоначальной настройки
- После усиления SSH удалённый вход разрешён только пользователю `devops`

### devops

- UID: 1001
- Входит в группу `sudo`
- Удалённый вход выполняется по SSH-ключу
- Парольная SSH-аутентификация отключена

Ключ на Windows:

`C:\Users\Redmi\.ssh\devops_vm`

Открытый ключ размещён на сервере в:

`/home/devops/.ssh/authorized_keys`

Права:

- `/home/devops/.ssh` — `700`
- `/home/devops/.ssh/authorized_keys` — `600`

## 5. Служба SSH

Дополнительный файл конфигурации:

`/etc/ssh/sshd_config.d/99-hardening.conf`

Параметры:

- `Port 2222`
- `PermitRootLogin no`
- `PasswordAuthentication no`
- `PubkeyAuthentication yes`
- `PermitEmptyPasswords no`
- `MaxAuthTries 3`
- `LoginGraceTime 30`
- `AllowUsers devops`
- `X11Forwarding no`
- `ClientAliveInterval 300`
- `ClientAliveCountMax 2`

Механизм `ssh.socket` отключён, используется `ssh.service`.

Подключение с Windows:

`ssh devops`

Подключение по локальному имени:

`ssh -i ~/.ssh/devops_vm -p 2222 devops@devops.local`

Полное доменное имя сервера:

`devops-vm.devops.local`

## 6. Правила межсетевого экрана

UFW активирован.

Политики по умолчанию:

- входящий трафик: `deny`
- исходящий трафик: `allow`

Разрешённые порты:

- `2222/tcp` — SSH, действие `LIMIT`
- `80/tcp` — HTTP
- `443/tcp` — HTTPS

Логирование UFW установлено в режим `medium`.

Порт `8080/tcp` закрыт. Проверка с хостовой системы приводит к записи `UFW BLOCK`.

## 7. Снимки состояния

Созданы следующие снимки VirtualBox:

1. `01-clean-install` — исходное состояние после установки системы
2. `02-keys-configured` — настроена аутентификация по SSH-ключу
3. `03-ssh-hardened` — выполнено усиление конфигурации SSH
