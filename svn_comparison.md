1 Ветвление в Git дешёвое — ветка это просто указатель на коммит (файл с хешем). В SVN дорогое — ветка это копия структуры каталогов в репозитории, требует обращения к серверу.

2 Нет, коммит в SVN без интернета невозможен — это централизованная система, коммит сразу отправляется на сервер. В Git коммит создаётся локально.

3 SVN предпочтительнее: тонкий контроль доступа к папкам, работа с большими бинарными файлами, простой линейный процесс, жёсткая централизация.
